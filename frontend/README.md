# frontend

React Progressive Web App (planned), with two interfaces:

- **Worker app:** record a voice note / video or type; hear the Skill Passport read back; listen to the top 5 matches; give per-employer consent.
- **Employer app:** describe the job by voice, video or text; see consenting workers with past ratings; rate each hire.

Design goals: installable to the home screen, small download, works on entry-level Android phones, offline caching and background upload via a service worker.

A simulated WhatsApp-style chat screen will live here for the prototype demo.
